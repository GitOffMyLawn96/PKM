# LLM dev tooling

**Scope:** Coding agents, IDE/CLI integrations (e.g. Claude Code), plugins, harnesses, meta-agents, and benchmark-driven agent improvement — tools developers use to build and run LLM-assisted software workflows.

**Out of scope:** General “AI productivity” monetization narratives (see [[wiki/domains/llm-monetization/overview|llm-monetization]]); company org design (see [[wiki/domains/org-ai-futures/overview|org-ai-futures]]).
