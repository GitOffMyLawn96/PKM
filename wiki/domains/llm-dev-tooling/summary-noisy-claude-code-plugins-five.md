# Noisy — five Claude Code plugins

**Source:** X Article by [@noisyb0y1](https://x.com/noisyb0y1/status/2040707651089178792), saved as `raw/inbox/Noisy on X_ _I spent a week testing Claude Code plugins. Here are 5 that actually worth it_ _ X.htm`.

**Note:** Strong **productivity / income claims** in the original (e.g. “100x,” dollar-per-day figures) are **not verified** here. The piece also promotes a **Telegram** channel — treat as **opinion + funnel**, not neutral review.

## Five plugins summarized (author)

1. **claude-mem** — session memory via hooks, local SQLite (`~/.claude-mem/`), optional localhost viewer; mentions “Endless Mode” beta.  
   - Source link in article: `github.com/thedotmack/claude-mem`

2. **obsidian-mind** — Obsidian vault automation, session hooks, slash commands, subagents, QMD semantic search.  
   - `github.com/breferrari/obsidian-mind`

3. **voicemode** — voice I/O for Claude Code; local Whisper + Kokoro or cloud fallback.  
   - `github.com/mbailey/voicemode`

4. **superpowers** (obra) — structured workflows: TDD, brainstorming, debugging discipline, skill authoring.  
   - `github.com/obra/superpowers`

5. **Compound Engineering** (EveryInc) — planning-heavy workflow (`/ce:plan`, `/ce:ideate`); claims multi-IDE support.  
   - `github.com/EveryInc/compound-engineering-plugin`

## Framing (author)

- Problem statement: default Claude Code is “forgetful,” text-only, and rushes to code; stack of plugins addresses memory, second-brain, voice, discipline, and planning.
