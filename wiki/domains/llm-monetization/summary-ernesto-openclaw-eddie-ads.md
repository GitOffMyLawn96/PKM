# Ernesto Lopez — Openclaw “Eddie” autonomous ad pipeline

**Source:** X Article by [@ErnestoSOFTWARE](https://x.com/ErnestoSOFTWARE/status/2033917717762191659), saved as `raw/inbox/Ernesto Lopez on X_ _We turned Openclaw into a self improving vibe marketer for our $300,000_yr app. _ _ X.htm`.

**Note:** **Sponsored** mention of **Arcads** with tracking link at end. Revenue and scale figures are **author claims**.

## Narrative

- **Problem:** One mobile app at **~\$300k/yr** scaled with **four** winning **TikTok Spark** creatives; creatives **fatigue** (~1–2 months); manual new winners are slow.
- **Agent “Eddie”** (Openclaw): end-to-end **ad creation** and iteration.

## Pipeline (author)

1. **Research** — Skill `ad-research`: **Apify** scrapes **Meta Ad Library**; sorts ads by age; downloads video; **Whisper** transcripts; hook/angle breakdown across competitors.
2. **Brand voice** — Markdown “brain”: `writing-rules.md` (banned AI-tells, references Wikipedia’s signs-of-AI-writing), plus `voice.md`, `product.md`, `icp.md` loaded before scripting.
3. **Scale scripts** — For each competitor ad: keep transcript + **rewrite** in brand voice; multiply by **ICP** variants; dozens–100+ variants per session.
4. **Production** — Top scripts → **human UGC** creators (\$15–50/video); bulk → **Arcads** API (AI actors / hooks); goal **100+ creatives / month**, Meta optimizes delivery.
5. **Closed loop** — Performance via **Singular** (MMP) back into Eddie; favors lower **CPA** directions; **generate → measure → regenerate**.
